### Backend (server)

- `server/index.js`:
  ```javascript
  const express = require('express');
  const http = require('http');
  const { Server } = require('socket.io');
  const cors = require('cors');

  const app = express();
  app.use(cors());

  const server = http.createServer(app);
  const io = new Server(server, {
    cors: { origin: '*' }
  });

  const rooms = new Map(); // roomID => Set of socket IDs

  io.on('connection', (socket) => {
    socket.on('join-room', (roomID) => {
      socket.join(roomID);
      if (!rooms.has(roomID)) rooms.set(roomID, new Set());
      rooms.get(roomID).add(socket.id);
      // Notify others in room
      socket.to(roomID).emit('user-joined', socket.id);
      // Send back all current users
      const users = Array.from(rooms.get(roomID));
      socket.emit('room-joined', users);
    });

    socket.on('offer', ({ to, offer }) => {
      io.to(to).emit('offer', { from: socket.id, offer });
    });

    socket.on('answer', ({ to, answer }) => {
      io.to(to).emit('answer', { from: socket.id, answer });
    });

    socket.on('ice-candidate', ({ to, candidate }) => {
      io.to(to).emit('ice-candidate', { from: socket.id, candidate });
    });

    socket.on('disconnect', () => {
      // Remove from all rooms
      for (const [roomID, sockets] of rooms) {
        if (sockets.has(socket.id)) {
          sockets.delete(socket.id);
          socket.to(roomID).emit('user-disconnected', socket.id);
          if (sockets.size === 0) rooms.delete(roomID);
        }
      }
    });
  });

  const PORT = process.env.PORT || 3001;
  server.listen(PORT, () => console.log(`Signaling server on ${PORT}`));
```

   – Extract room ID from hash.
   – Connect to signalling server using useSocket (reads the server URL from environment variable VITE_SIGNALING_SERVER, default http://localhost:3001).
   – Get user media (audio+video) with getUserMedia.
   – Set up WebRTC with useWebRTC (pass socket, stream, roomID).
   – Create a hidden video element for gesture detection, set its srcObject to the local stream. Run useGesture on that element.
   – Use useSpells to map gestures to spells with cooldowns.
   – Render:
   • Two VideoTile components (local + remote).
   • SpellOverlay canvas positioned absolutely over the local video tile, showing AR effects.
   • SpellPanel showing spell icons/names with cooldown indicators.
   • DrawingBoard (overlay) when toggled.
   – Clean up all media tracks, peer connections, and MediaPipe instance on unmount.
5. VideoTile.jsx
   – Accepts stream and muted/placeholder props. Styled with a glowing magical frame.
6. SpellOverlay.jsx
   – Manages a Three.js scene on a transparent canvas matching the video dimensions.
   – Subscribes to landmark data (from useGesture) and the current spell (from useSpells).
   – When a spell is cast, invokes functions from arEffects.js to start the effect (e.g., create lumos orb, fire particles, etc.) at the landmark position.
   – Uses requestAnimationFrame for smooth animations, automatically removing finished effects.
7. DrawingBoard.jsx
   – A canvas element with pointer event listeners.
   – On stroke, collects points and sends via data channel (from useWebRTC).
   – Receives draw/clear messages and renders on the canvas.
   – Toggle button to show/hide the canvas.
8. SpellPanel.jsx
   – Displays the four spells with a cooldown ring and highlights the currently cast spell.

Hooks:

· useSocket.js: creates and returns a socket instance, handles connect/disconnect.
· useWebRTC.js:
  • Creates RTCPeerConnection with google STUN servers.
  • Adds local stream tracks.
  • Creates data channel (label 'drawing') for the initiator, listens for 'datachannel' on the receiver.
  • Exposes: localStream, remoteStream, dataChannel, initiateCall, etc.
· useGesture.js:
  • Loads MediaPipe Hands (with CDN locateFile).
  • Attaches a Camera instance to a hidden video element.
  • On results, analyses landmarks to determine gesture (open palm, fist, pointing, L‑shape).
  • Returns currentGesture and landmarks.
· useSpells.js:
  • Takes currentGesture, maps to spells, enforces cooldown.
  • Exposes currentSpell, onSpellCast callback.
· useDrawing.js:
  • Manages local drawing canvas events, sends data over data channel.
  • Listens for remote drawing messages and draws strokes.

Utils:

· spells.js: export array of spell definitions with name, gesture, colour, sound file path.
· arEffects.js:
  • createLumos(scene, position), createIncendio(scene, position), etc.
  • Each creates Three.js objects and adds them to the scene, with a cleanup timeout.

** Sound files:**

· Place short silent placeholder MP3 files in client/public/sounds/ to avoid 404 errors. The spell‑cast code will try to play the audio and catch any error if the file is missing.
